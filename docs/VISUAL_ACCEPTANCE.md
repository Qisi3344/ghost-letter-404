# 视觉打回重做通知 · 长期验收规范

**适用仓库：** Qisi3344/ghost-letter-404  
**状态：** 当前主舞台混用新旧视觉、内室低精度草模均被驳回；这里定义后续修订的硬性要求。  
**审美最终批准人：** 仓库所有者（用户）；自动测试无法替代视觉批准。

## 1. 本轮否决的具体问题
- 新 P0 量子星轨直接拼回原版平面底盘、齿轮、拱门等旧视觉系统，造成材质、透视、结构语言割裂。禁止以局部替换旧场景的方式宣称「视觉重构完成」。
- 新内室变成几块长方体家具和低精度打字机，像未经雕琢的等距白模。书柜、平台、房间、打字机均缺乏设计上的机械因果、工艺层次和细节密度。
- 三条圆环即使具有等距投影，若出现不合理交错、曲面分档、假玻璃、没修正的遮挡，仍不能通过。
- 以上都是**审美与空间品质**问题，不是交互按钮数量、CSS 特效或功能测试可以解决的。

## 2. 锁定的主舞台方案
- **中央量子悬浮 / 无柱体**：完全移除可见的左右立柱、轴承、铰接节点及其他支撑物。无需维修/调试显形。
- **三层金属星轨**：外/中/内三环必须可数、体积清楚，分别采用不同空间姿态；其相交是画面投影中的遮挡，不是几何实体互相穿透。允许用内部虚拟转动轴与层级控制运动，但不得渲染可见连接件。
- **星核**：玻璃边缘、内腔、反射高光、星球/能量中心、与轨道的正确前后关系。禁止纯圆形渐变冒充玻璃。
- **装置与底座**：统一完整重设计，不沿用旧版线框底座和成排装饰齿轮。场景应体现雕塑性和神秘的未来机械工艺；若底座令构图累赘，可弱化为简单精致的悬浮台座，但不强求支架。
- **视角**：统一空间坐标与相机，能看出顶部、厚度、内外侧和层层嵌套；绝不返回正面平面舞台风格。
- **细节**：连续金属表面、倒角、适度刻纹、接触或自遮挡阴影、层级分明。避免 96 个独立环段形成切片接缝的外观。
- **空间感**：至少前景轨道/主体玻璃/后景轨道存在可信的遮挡、明暗和深度分离。光效需依附物体，不可用满屏发光掩盖结构。

## 3. 锁定的内室方案
- **主题：宇宙折叠仪深处的幽灵邮局。** 不能是普通书房、普通等距家具摆设。
- **主角：** 机械打字机与送信系统，必须具有真实层叠的键帽、连杆/传动、卷纸辊、纸槽、封蜡/信封机构、装饰性但有理由的工艺结构；不是用几个梯形和圆点凑一个键盘。
- **室内空间：** 机器内部的舱壁、弧形包围、折叠层、星光管线、隐藏收纳等，有进深和结构包裹感。书架可以有但不能喧宾夺主。
- **灯光：** 聚焦写信动作与纸张；紫色空间冷光 + 柔和暖金局部光，保持亲密温暖的万圣节氛围。
- **双幽灵：** Clawd 和 GPT 的尺度、落点、悬浮/触碰关系与空间视角一致；不能像两个贴在场景上的图标。
- 这个空间应让玩家感觉「打开宇宙仪后发现秘密」，不是走进另一张无关的 4399 游戏地图。

## 4. 必须保留的角色造型
- **Clawd** 原版的橘色立方螃蟹、蓝色长方眼、八条短腿必须能辨认；幽灵布罩和巫师帽不能抹去这些标识。
- **GPT** 原版的软白团子鬼、黑色结形标志、圆头小手与幽灵尾轮廓必须能辨认；披风/巫师帽为轻量装扮。
- 以提供的原始参考图为形状权威；角色正面、侧面与场景尺度要一致。

## 5. 强制交付流程
1. **A / 主舞台原型**：独立静态页面；1× 完整浏览器截图、4× 星轨与玻璃局部图，截图中必须能数出三环，并且不存在可见支柱、轴承帽与节点。记录几何、材质和遮挡实现方式。发给用户验收。
2. **B / 内室原型**：在 A 通过后创建独立场景；1× 完整浏览器截图、4× 打字机与房间空间细节图；对照参考设计验收。
3. **C / 整合**：只有 A 与 B 被用户明确认可后，才能移植进 React 主体验，重建统一 UI、转场与交互。
4. **复核**：桌面和手机实际浏览器截图、动画过程或多帧遮挡检查、角色姿态、信件导出与入口流程；记录构建/测试结果。
5. **GitHub**：独立分支与草稿 PR；不要直接改 main，不要绕过用户视觉批准自行合并。

### 通过条件
- 不再有明显 Flash / 4399 式二维贴片画面；
- 没有新旧设计混搭；
- 星轨和内室均有清楚的空间结构、精细实体材质与视觉中心；
- 真实运行截图与交互渲染相符；
- 用户明确确认「通过」后才进入下一阶段。

### 退回条件
任意出现下述问题即可退回：少于三层轨道；露出柱体/连接节点；错乱遮挡和穿模；单靠渐变大圆表现星核；低质家具白模；将新场景贴回旧舞台；以构建成功冒充审美通过；只交概念图不交真实浏览器截图。
